# Project history — evidence-oriented summary

The private archive retains accessible Git histories and branch-specific reports; this public repository intentionally begins with a clean history.

- Upstream roots: a PC static recompilation toolchain and Red Alert 2/Yuri's Revenge host experiments. Retain upstream attribution and license boundaries; the games are not licensed by their tooling.
- Late October 2026: protected input, WORLD observations, identity binding, storage/recovery practices and skirmish/economy experiments.
- Early November: building/infantry/combat observations, stronger source freshness and acknowledgment/closure semantics; Original and lifted evidence remained separate.
- November 3 onward: codebase audits and targeted consolidation; source snapshots and clean private rebuild experiments.
- November 7–8: focus changed to human-playable isolated game executables, ordinary window input and passive reporting. Independent Reunion client work was cancelled.
- Manual checkpoint 72c9eb0eb52ca5c8f32799c9bc1d63f92f4887cf had owner-reported Allied play. Checkpoint 5422606b2dc452a0641037b2c5e507133dd9580a has a later user-reported victory record; neither is a blanket new-version certification.
- Stock spawn, rendering and retail-named isolated launch experiments followed. 905d06c2b6e224c45f1c4ec398c0d4d3e83f3b5a has bounded Allied/Soviet/Yuri scenario initialization and normal-exit evidence, plus selected campaign/load observations. Actual installed Reunion handoff and vendor binary compatibility remained unresolved.
- November 12–14: FIADD/movement investigations, e4becf2 candidate, Grok's independent a33579d dispatch prototype, Codex review/integration at 7611b43. Corrected the vendor Hook inventory, built matching symbols and preserved unresolved startup failures.
- A separate latest research branch preserved audit gates and user-driven Original modified-game profiling at 4ac73d6, 547ffb3 and 3d4d03d. It was archived separately, not merged into the 7611b43 runtime candidate.
- November 14: the owner suspended active development indefinitely and requested preservation, a conservative public subset, and separately approved disk cleanup.

Descriptions of earlier game activity derive from frozen reports and user testimony; they were not replayed during archival. Dates in imported Git histories can be rebased or reflect upstream work; they should not be mistaken for the owner's first project day.
